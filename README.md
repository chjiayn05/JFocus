# JFocus - 專注與活動監控系統

JFocus 是一款專為提升專注力設計的跨平台桌面軟體。結合寶可夢成長與收集機制、待辦清單與系統級活動監控，提供極佳的專注回饋體驗。

---

## 一、專案安裝及執行之步驟

### 系統需求與環境準備
- **Java JDK 21**：專案使用 Java 21 新特性（包含新版 Process API），請確保已安裝 JDK 21。
- **Maven 3.6+**：專案依賴 Maven 進行建置。
- **作業系統**：支援 Windows 與 macOS。

### 安裝與編譯步驟
1. **複製專案**：
   ```bash
   git clone <專案倉庫連結>
   cd JFocus
   ```
2. **清除舊建置並編譯專案**：
   ```bash
   mvn clean compile
   ```
3. **執行應用程式**：
   ```bash
   mvn javafx:run
   ```

## 二、其他想特別說明之事項

本系統包含以下幾項具備技術亮點的底層與跨平台設計：

### 跨平台底層監控 (JNA Win32 & AppleScript)
- **Windows 端**：使用 JNA (Java Native Access) 直接對接 `user32.dll` 與 `dwmapi.dll`，在不影響系統效能的情況下，精確取得最上層前台視窗的控制代碼 (HWND)、標題與 PID。
- **macOS 端**：利用內建 `osascript` 與 AppleScript 向 `System Events` 發起高權限查詢，快速捕捉當前最上層的活動應用程式與視窗。

### macOS 輔助使用授權申請
- 由於 macOS 對系統級視窗監控與 AppleScript 有嚴格的權限規範，系統首次運行時會自動調用 `CoreFoundation` 判定是否已取得輔助使用權限（Accessibility）。若未取得，系統會自動彈出提示引導使用者開啟 macOS「系統設定 → 隱私權與安全性 → 輔助使用」授權。

### 影音播放排除機制 (網格像素變動率)
- 為避免使用者在電腦前「觀看線上教學影片」或「聽講座」時，因長期未移動滑鼠鍵盤而被判定為「閒置（掛網）」，系統使用 Java AWT `Robot` 定時截圖並進行像素抽樣。當畫面像素變動比例大於 2% 時，系統會自動判定為活躍狀態，避免扣除其寶貴的專注時間，精準解決了實體鍵鼠偵測的誤判痛點。
